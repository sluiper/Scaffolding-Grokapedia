## 1. Purpose of terminology discipline

Scaffold communication fails when Arabic-speaking crews, English supervisors, and proprietary-system manuals use different words for the same member. This chapter locks **working English terms** used across the encyclopedia, provides **Arabic equivalents for the top 20 terms**, and maps each numeric term back to MCR. [SYNTHESIS]

Do not invent synonym tables that invent capacities. Terms that carry numbers always point to MCR.

## 5. System-language caution (T&F vs proprietary)

| Concept (encyclopedia English) | Tube & fitting language | Cuplok / Ringlock language (typical) |
|--------------------------------|-------------------------|--------------------------------------|
| Vertical member | Standard / post | Standard |
| Longitudinal horizontal | Ledger | Ledger |
| Transverse horizontal | Transom | Transom / ledger (system-dependent) |
| Diagonal | Brace tube + swivel | Diagonal / brace with wedge or rosette |
| Platform | Boards / metal decks | System decks / boards |
| Node connection | Coupler at tube intersection | Captive cup / ring / wedge |

Cuplok / Ringlock use manufacturer terms that map **conceptually** but not always 1:1 to coupler language. Always follow manufacturer erection manuals for proprietary node rules (**MCR-039**; **GAP-022**). [SYNTHESIS]

## 6. Worked example — term disambiguation on site [DERIVED]

**Scenario:** Supervisor says “add a brace at the next bay”; scaffolder fits a **horizontal ledger** instead of a **diagonal brace**.

| Check | Correct term | Wrong term | Control |
|-------|--------------|------------|---------|
| Member geometry | Diagonal tube, angle **35°–55°** from horizontal | Horizontal ledger (already part of frame) | MCR-016 |
| Connection | Swivel coupler at non-90° | Right-angle only if true 90° | MCR-009 |
| Location | Nearest to **node point** | Mid-bay far from node | MCR-016 |

**Arabic toolbox line (working):**  
“الدعامة القطرية (بريس) بزاوية ٣٥–٥٥ درجة، أقرب ما يمكن لنقطة الالتقاء — ليست عارضة أفقية.” [SYNTHESIS]
