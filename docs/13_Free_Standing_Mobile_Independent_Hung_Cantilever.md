# Chapter 13 — Free-Standing, Mobile, Independent, Hung, Cantilever

**Status:** Production draft v0.3  
**Date:** 28 July 2026  

## MCR Mapping

MCR-017–020, 032, 040, 041, 056–059, 064, 045, 058.

---

## 1. Free-standing tower

- Four standards only.  
- **External:** height ≤ **3 ×** min base dimension (**MCR-017**).  
- **Internal:** height ≤ **4 ×** min base (**MCR-018**).  
- Brace all four sides.  
- Plan braces at **top, kicker, every third lift** (**MCR-057**).  

[CITATION: PPTX-M1 s39]

## 2. Mobile tower

- Four standards on **caster wheels**.  
- Height ≤ **4 ×** min base; outriggers if exceeded (**MCR-019**).  
- Brace four sides; plan brace bottom, top, intermediate lifts.  
- **Lock casters** during use; **no person or material** while moving.  
- Prefer **internal ladder**; external only vertical on **narrow side** (**MCR-064**).  
- Caster diameter: light **≥ 120 mm**; medium **≥ 170 mm** (**MCR-056**).  

[CITATION: PPTX-M1 s40]

## 3. Independent scaffold

- Two posts across width + multiple along length (**MCR-041**).  
- Face bracing both ends + every **5th** line of standards (**MCR-020**).  
- Ledger bracing alternate lines.  
- Façade bracing patterns: single / double / continuous (figures s42).  

## 4. Suspended / underhung

- Hung from structural I-beams; posts form tie around section.  
- **Trapeze** assist tube for scaffolders: max **600 mm from ledger** (**MCR-040** — GAP-008 closed).  
- Boarding via transom/ledger or ladder beams.  

[CITATION: PPTX-M1 s43]

## 5. Cantilever

- Platform extends beyond inside standards.  
- Support: transom/ledger + **raker 65°–75°** to horizontal (**MCR-032**).  
- Raker fixed to inside standard; **single tube — no splice** (**MCR-059**).  
- Length **≤ 3 m** without design; beyond → design (deck cites Aramco CSM-II) (**MCR-058**, **MCR-045**).  

[CITATION: PPTX-M1 s44]

## 6. Worked example — free-standing external limit [DERIVED]

Base min dimension = 1.5 m.  
Max external free-standing height = 3 × 1.5 = **4.5 m** (MCR-017).  
If required height 6 m → not free-standing external without increasing base / tying / redesign.
