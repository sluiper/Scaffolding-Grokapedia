## Unit resolution

PPTX text “N sqm” is **not SI-coherent** for scaffold service loads (would be 0.75 N/m² ≈ 0.000075 kN/m² — absurd).  
**Interpretation [DERIVED]:** training deck omitted the “k” — values are **kN/m²**.  
Matches EN 12811-1 Table 3 restatements exactly for classes 1–4.

## Design notes (secondary — not for exam until primary)

- Concentrated loads F1/F2 and partial area q2 (classes 4–6) can govern design even when UDL ok.
- Class 1 platforms often still need Class 2 unit capacity per EN restatements — do not under-board Class 1.
