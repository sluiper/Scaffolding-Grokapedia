## 5. NEW numeric / operational extract — SATORP STORP orientation

**Source:** `Documents/Training/STORP TRAINING/FINAL SAFETY ORIENTATION 2025 Rev 02.pptx`  
**Scope:** **SATORP client site** orientation (not Anabeeb global law). Use under client matrix only.

### 5.1 Scaffold tagging + harness (slide 50; quiz slide 56)

| Tag | SATORP rule (as taught) |
|-----|-------------------------|
| **Red** | Scaffold **not safe to use**; **only scaffold erectors** may access, **with full body harness** |
| **Green** | Passed inspection; **safe to use**; full body harness **not required** (general user rule on this client deck) |
| **Yellow** (slide 50 text incomplete colour name; quiz confirms) | Scaffold may be incomplete / modified / hazard to users; **full body harness required** |

**Interface conflict flag (do not flatten):**  
Anabeeb WAH-P010 requires **100% tie-off** when working at height (double lanyards or SRL). SATORP green-tag “harness not required” is **client user guidance for completed platforms**, not a waiver of Anabeeb fall-arrest hierarchy where edge/ incomplete conditions apply. Encyclopedia must teach **most stringent applicable rule** for the site.

### 5.2 Fall clearance example (slide 54)

| Symbol | Meaning | Example value |
|--------|---------|---------------|
| RD | Required distance (anchor to nearest obstruction below) | **17.5 ft** |
| LL | Lanyard length | **6 ft** |
| DD | Deceleration distance | **3.5 ft** |
| HH | Height of harness / D-ring allowance | **6 ft** |
| C | Clearance to obstruction | **2 ft** |
| Formula | **RD = LL + DD + HH + C** | 6+3.5+6+2 = 17.5 |
| Unit note on slide | 1 m ≈ 2.8 ft; 1.8 m ≈ 5.9 ft | Approximate teaching figures |

**Caveat:** Typical training example only; manufacturer SRL/lanyard data and client standard govern real calculation. Do not mark Visible without primary SATORP / manufacturer source.

### 5.3 Turnaround lessons (slides 55, 63)

Operational controls taught from prior TA:

1. Determine required scaffold **height** and prepare **scaffold plan**.  
2. **Adequate supervision** during erect & dismantle.  
3. **Do not modify scaffolds while in use** (aligns MCR-060).  
4. Falling objects from scaffolds/platforms → use **safety nets** and **tool bracelets/lanyards** (aligns MCR-047 / tool control).

### 5.4 Working at height safe/unsafe (slide 16)

- Use fall prevention system per JSA/risk assessment.  
- Check fall protection before use.  
- Secure tools/loose objects.  
- **Never** forget 100% tie-off; work at height if not trained; leave open fall area without barrier.
