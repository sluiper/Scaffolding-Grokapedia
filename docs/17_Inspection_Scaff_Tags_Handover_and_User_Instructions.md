## 1. Inspection gate (Anabeeb WAH)

1. All scaffolds shall be **inspected and approved prior to use**.  
2. Tagging system shall clearly indicate status.  
3. Tags displayed **at all access points**.  

[CITATION: WAH-P010] **MCR-029.**

**GAP-004:** Reinspection interval, competent inspector grade, and tag validity period **not** stated in WAH extract or Module-1. Planned forms: master list links “Scaffold Tag & Form” to SWP-019 (**GAP-001**).

## 2. Tag colour system

| Colour | WAH wording | Module-1 operational detail |
|--------|-------------|------------------------------|
| **Green** | Safe for Use | Scaffold is safe |
| **Yellow** | Restricted Use | Harness & lanyard **mandatory** for users |
| **Red** | Do Not Use | **Only scaffolders** allowed |

[CITATION: WAH-P010 + PPTX-M1 s62–s64] **MCR-028.**

Only an **authorized person** shall fill the scaff-tag. [CITATION: PPTX s62]

## 3. End-user pre-use ritual

Before each use, end user must:

1. Find tag at access point.  
2. Confirm colour matches intended work and controls.  
3. Not use if tag missing, damaged, red, or unclear — report to supervisor.  

[CITATION: PPTX s62] **MCR-029.**
