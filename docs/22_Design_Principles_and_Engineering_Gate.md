# Section 22 — Design Principles & When Engineering Is Required

**Status:** Production draft v0.5  

## MCR Mapping

MCR-045, 058, 015/054, 040, 017–019 · GAP-007/015.

---

## 1. Standard vs engineered

**Standard / compliance scaffold:** within published good-practice sheets (e.g. TG20) or manufacturer system manuals for the exact configuration.

**Engineered scaffold:** requires competent design output (drawing, loads, tie schedule, sequence) when outside those sheets.

## 2. Hard triggers (encyclopedia)

| Trigger | Source |
|---------|--------|
| Cantilever platform **> 3 m** | MCR-058 (deck/Aramco cite) |
| Bridge / span / ladder-beam special | MCR-024, training ADV |
| Special / heavy loads beyond class | MCR-015/054 + MCR-045 |
| Wind-sensitive cladding / netting significant area | [SYNTHESIS] design |
| Free-stand ratios exceeded without outriggers/ties | MCR-017–019 |
| Public protection / complex SIMOPS | Client often requires design |
| Hung/suspended non-standard | Ch13 + design |

## 3. Design deliverables (minimum checklist) [SYNTHESIS]

- Duty class and max working lifts  
- Plan/elevation; tie positions and type  
- Bracing scheme  
- Foundation/sole assumptions  
- Sequence notes for incomplete edge protection  
- Temporary works designer competence statement  

## 4. Scaffolder duty

Do not “improve” design on site without designer/supervisor change control (**MCR-060** family).
