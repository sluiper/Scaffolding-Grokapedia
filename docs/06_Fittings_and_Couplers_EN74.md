## 1. General requirements

- Couplers conform to **EN 74**; mark brand, year of manufacture, class **A or B**.  
- Pressed or drop-forged; galvanized/zinc coated typical.  
- Maintain free-running, lightly lubricated nuts/bolts; examine before use.  
- **Do not expose couplers to heat.**  
- Deck preference for load-bearing right-angle: **drop-forged only acceptable** (PPTX s14).  

[CITATION: PPTX-M1 s14, s22]

## 2. Right-angle / double coupler (load-bearing)

| Attribute | Value |
|-----------|-------|
| Use | Connect tubes at 90° |
| Failure mode (deck) | Slip along tube |
| Class B SWL (adopted) | **9.1 kN** (EN74-sec + PPTX s23) |
| Deck conflict | s14 stated 9.4 kN — **discarded** (T1) |

**MCR-008.** Primary EN 74-1 table still required for Visible (**GAP-007**).

## 3. Swivel coupler (load-bearing)

| Attribute | Value |
|-----------|-------|
| Use | Any angle **other than 90°**; braces; some splices |
| Class B SWL (adopted) | **~9.1 kN** slip class (aligned T1) |
| Misuse | Do not use as primary beam hanger / load path substitute for right design |

**MCR-009.**

## 4. Putlog / single coupler (non-load-bearing)

| Attribute | Value |
|-----------|-------|
| Use | Connect boarded transom to ledgers |
| SWL (deck) | **0.53 kN** (axial pull-out style) |
| Rule | **Never** use as structural load-bearing joint |

**MCR-010.** **GAP-013** primary confirm.

## 5. Board retaining coupler

Clamps board over transom. [CITATION: PPTX-M1 s17] No numeric SWL in deck.

## 6. Sleeve / end-to-end coupler

| Source | Value | Status |
|--------|-------|--------|
| PPTX s18 | Class B **3.0 kN or 0.59 kN/m**; fails tension/bending | Conflict |
| PPTX s24 | **0.53 kN**; failure bending | Conflict |
| Trade web | Often misquotes slip ≥9 kN (right-angle class) — **not trusted** | Reject for MCR |

**MCR-011:** SWL **unresolved**. Process control that remains firm: **stagger sleeve joints** in scaffold.  
**GAP-012.**

## 7. Girder couplers

- Clamp tubes to structural sections (I-beams/channels).  
- Always use **in pairs**.  
- Prefer **check (safety) couplers**.  
- **Double couplers not allowed** for structural section connections.  

**MCR-012, 034, 042.**

## 8. Joint pins (internal spigot)

Expanding spigot grips inside tubes. **Not** for bending or tension positions. [CITATION: PPTX-M1 s21] **MCR-013.**
