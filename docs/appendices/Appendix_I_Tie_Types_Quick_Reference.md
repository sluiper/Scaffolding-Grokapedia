# Appendix I — Tie Types Quick Reference (Draft)

| Type | Idea | Notes |
|------|------|-------|
| Box | Tubes around column/I-beam all sides | Preferred when geometry allows |
| Lip | L-shape when full box impossible | Incomplete box substitute |
| Through | Through window/opening | Building opening available |
| Drill / cast-in | Anchor into structure | Competent install |

**Couplers:** right-angle for tube ties; girder **pairs + check** on steel (**MCR-042/034**).  
**Do not invent tie kN** — GAP-015 until design table loaded.  
**Never remove ties** without scaffolder plan (MCR-060 family).
