# Appendix D — Free-Standing / Mobile Tower Ratio Card (Draft)

| Configuration | Max height rule | Plan braces | Extra |
|---------------|-----------------|-------------|-------|
| Free-standing **external** | ≤ **3 ×** min base | Top, kicker, every 3rd lift | Brace 4 sides |
| Free-standing **internal** | ≤ **4 ×** min base | Same | Brace 4 sides |
| **Mobile** tower | ≤ **4 ×** min base (outriggers if more) | Bottom, top, intermediate | Lock casters; no one aboard while moving |

**Casters:** light ≥ 120 mm; medium ≥ 170 mm dia.  
**Access:** prefer internal ladder; external only vertical on narrow side.  

**MCR-017–019, 056–057, 064.**
