# Appendix B — Coupler Selection & SWL Card (Draft)

| Coupler | Use | Class B SWL (Drafting) | Never |
|---------|-----|------------------------|-------|
| Right-angle / double | 90° load-bearing | **9.1 kN** slip (MCR-008) | Soft/defective; heat-damaged |
| Swivel | Non-90° braces etc. | **~9.1 kN** (MCR-009) | Beam hanger misuse |
| Putlog / single | Board connection | **0.53 kN** HOLD (MCR-010) | Structural load path |
| Sleeve | Co-axial join | **UNRESOLVED** (MCR-011) | Unstaggered lines |
| Girder | To structural steel | Pairs + check (MCR-012/034) | Single girder; double on steel |
| Joint pin | Internal spigot | — | Bending/tension positions |

EN 74 mark: brand, year, class A/B. Prefer drop-forged for load-bearing doubles (training).  
**Not laminated until primary EN74 or human freeze.**
