# Section 28 — Emergency Response (Scaffold Context)

**Status:** Production draft v0.5  

## Scenarios

| Scenario | Immediate actions [SYNTHESIS] |
|----------|-------------------------------|
| Fall from height | Stop work; first aid/BLS per site; emergency services; preserve scene; notify HSE/PM |
| Partial collapse | Evacuate; account for people; no re-entry until engineer/scaffold competent person; red tag |
| Struck-by / dropped object | Medical; isolate drop zone; stop overhead work |
| Medical on platform | Rescue plan pre-job; do not improvise unsafe lower without method |
| Weather sudden | Clear platforms; secure materials; stop height work |
