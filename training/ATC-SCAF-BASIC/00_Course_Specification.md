## 1. Intent

Qualify new scaffolders to **erect, modify, and dismantle** basic tube-and-fitting / common system scaffolds under supervision, using Anabeeb safety rules, tags, and MCR-linked limits.

## 2. Entry gates

- Fit for work at height (company medical practice)  
- Site induction / PTW awareness  
- Literate in course language or translator  
- Willingness to stop-work and never-rules discipline  

## 3. Pass criteria (all required)

| Element | Standard |
|---------|----------|
| Theory exam | ≥ **80%** (`04_Theory_Exam.md`) |
| Practical competency | **Pass all critical** items (`03_Practical_Competency_Checklist.md`) |
| Behavioural | Tag discipline, drop zone, stop-work |
| Attendance | Full programme |

## 5. Build rules

1. Cite **MCR-IDs** in exam items; for RF-style constants use MCR lookup only.  
2. Coupler SWL exam items: **9.1 kN Class B** (MCR-008) as Drafting answer; note primary EN74 pending.  
3. Sleeve SWL: **do not** test a single number — test **stagger** + “do not invent”.  
4. Dual duty systems: both EN and Aramco tables as awareness (MCR-015/054).
