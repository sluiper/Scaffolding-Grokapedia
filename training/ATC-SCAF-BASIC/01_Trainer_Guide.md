# ATC-SCAF-BASIC — Trainer Guide

**Class size:** ≤10 · **Ratio:** prefer 1 trainer + 1 practical assistant for yard work  

## Pre-course

- [ ] Yard space + materials (tube, fittings, boards, sole boards, tags)  
- [ ] MCR extract handout (Drafting watermark if printed)  
- [ ] Red/yellow/green tag samples  
- [ ] Gin wheel demo only if SWL tagged 50 kg training unit  
- [ ] PTW / barricade for practical area  

## Day scripts (summary)

### Day 1 — Safety culture
- Objectives; major risks (fall, collapse, struck-by)  
- WAH 1.8 m; guardrail Anabeeb band; tool lanyards  
- Tags G/Y/R; user vs scaffolder roles  
- Never rules drill (App G)  
- **Practical:** barricade drop zone; tag placement  

### Day 2 — Materials & fittings
- Tubes 48.3 / Type 3 vs 4; never cut on site  
- Sole boards / base jack 2/3  
- Coupler zoo: double, swivel, putlog, sleeve, girder, pin  
- **Practical:** fit each coupler type correctly; reject putlog on ledger-standard structural joint  

### Day 3 — Structures
- Duty classes EN vs Aramco  
- Brace 35–55°; face every 5th; plan braces free-stand  
- Ties: box/lip/through/drill; girder pairs  
- Free-stand 3×/4×; mobile 4× + casters  
- **Practical:** small independent bay + face brace + box tie demo  

### Day 4 — Access & special
- Ladder 4:1, 1 m/3 rungs, hatch 675×900  
- Gin wheel 50 kg / 750 mm / 2 doubles  
- Hung trapeze ≤600 mm; cantilever ≤3 m / raker no splice  
- Inspection & handover  
- **Practical:** ladder install; pre-use checklist complete  

### Day 5 — Assessment
- Practical stations (checklist criticals)  
- Theory exam  
- Debrief gaps  

## Safety for training yard

Stop if weather adverse; 100% tie-off when required by height/method; no live overloading experiments.
