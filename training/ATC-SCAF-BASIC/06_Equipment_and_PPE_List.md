# ATC-SCAF-BASIC — Equipment & PPE List

## PPE (minimum)

- Safety helmet, safety boots, high-vis  
- Safety glasses / gloves as task  
- Full-body harness + twin lanyard or SRL as method requires  
- Tool lanyards / scaffolder belt as required  

## Training materials (indicative)

| Item | Qty guidance |
|------|----------------|
| EN39 tubes assorted lengths | enough for 1–2 small towers |
| Right-angle Class B couplers | 40+ |
| Swivel couplers | 20+ |
| Putlog / board retainers | 10+ |
| Sleeve couplers | 10+ |
| Base plates + jacks | 8–12 |
| Sole boards | 8+ |
| Scaffold boards / decks | full platform |
| Ladder + clamps | 1–2 |
| Scaff-tags G/Y/R | set |
| Gin wheel + rope (50 kg SWL marked) | optional |
| Barricade tape / signs | yard set |
| First aid / emergency plan | site |

## Reject before class

Defective tubes, seized couplers, cracked boards, untagged gin wheels.
