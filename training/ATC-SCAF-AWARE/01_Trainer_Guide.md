## Trainer rules

1. Quote **MCR-IDs**; do not invent SWL numbers beyond “use MCR / tag / supervisor”.  
2. Emphasize **Red = scaffolders only**; **Yellow = harness mandatory**.  
3. If site SWP-019 exists later, re-align tag wording.  
4. Heat/weather: stop work at height per WAH — no wind number if not on tag/permit.
