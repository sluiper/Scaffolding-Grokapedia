# Anabeeb AIMS-L2-HSE-P-007 — Permit to Work — Summary (Scaffold interface)

**Source:** `Desktop/TVTC_Site_Visit_Pack/04_Quality_and_Safety/HSE_Procedures_AIMS/AIMS-L2-HSE-P-007_PTW.docx`  
**Extracted:** 28 July 2026  
**Scope of this summary:** rules that gate scaffold erect/modify/use on **client premises**.

## Purpose

Complements the **client’s** PTW system at client premises. Applies to jobs where client PTW is applicable.

## Roles

| Role | Duty (summary) |
|------|----------------|
| Project Leader | Accountable that PTW procedure is followed; receivers qualified; supervisors know client PTW |
| Job supervisor | Right permit type; **no job without PTW even if minor**; enforce PTW; close permits end of shift or as stated |
| Permit receiver | Understand conditions before sign; remain on site or transfer; joint close with issuer even if incomplete; hard copy posted at workplace; client procedure compliance |
| Permit issuer | Client-authorized; joint site inspection before issue |

## Hard rules (scaffolding implications)

| Rule | Scaffold implication | Proposed MCR |
|------|----------------------|--------------|
| No work without valid PTW | Erect/modify/dismantle and often use on client sites need valid permit | MCR-066 |
| Issuer+receiver only | No informal “go ahead” | MCR-066 |
| Joint site inspection before issue | Walk scaffold location with issuer | MCR-066 |
| Normally single operating shift | Re-permit next shift | MCR-067 |
| Not whole unit on one permit | Define scaffold location limits clearly | MCR-066 |
| Void if conditions change | Weather, scope, red-tag period, SIMOPS change → stop + new PTW | MCR-068 |
| Cancel on emergency | Evacuate; cancel | MCR-068 |
| Close on completion or expiry | Closeout with issuer | MCR-067 |
| Gas test for hot work / CSE | If scaffold for hot work/CSE — extra certs not enough alone | MCR-066 notes |
| Isolation required for equipment work | Interface when scaffold around process equipment | MCR-066 notes |
