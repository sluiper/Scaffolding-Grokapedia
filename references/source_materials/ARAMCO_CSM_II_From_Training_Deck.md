## 1. Duty load ratings — slide 38

Deck presents **two parallel tables**:

### British Standard (TG20:13) — as printed on deck

| Duty | Load | Purpose (deck) |
|------|------|----------------|
| Very light duty | **0.75 kN/m²** (deck text “0.75 N sqm” — treat as kN/m²) | Access & walkway |
| Light duty | **1.5 kN/m²** | Painting, inspection, cleaning |
| General / medium | **2.0 kN/m²** | Building works |
| Heavy duty | **3.0 kN/m²** | Masonry, concrete works |

### Aramco Standard (CSM–II) — as printed on deck

| Duty | Load | Purpose (deck) |
|------|------|----------------|
| Light duty | **1.2 kN/m²** | Painting, inspection, cleaning |
| Medium duty | **2.4 kN/m²** | Building works |
| Special duty | **> 2.4 kN/m²** | Masonry, concrete works |

**Unit note:** Slide text says “N sqm”; industry duty tables are almost always **kN/m²**. Encyclopedia must normalise units with dual-model check before MCR Visible (known family issue).

**Site rule:** On Aramco work, use **CSM-II column** if client requires; on British-system work use TG20 column; Anabeeb may be stricter.

## 2. Cantilever platform limit — slide 44

> “A cantilever platform shall not exceed **3 m** beyond which requires design of scaffold. **(Aramco CSM-II)**”

- Raker inclination **65°–75°** to horizontal (deck geometry — not labelled CSM in same sentence).  
- Raker = **single tube, no splicing**.  
- Extended platform supported on transom & ledger fixed to raker to inside standard.

## 3. Free-standing / mobile tower ratios (deck — not always labelled CSM)

| Type | Height limit (deck) |
|------|---------------------|
| External free-standing tower | ≤ **3 ×** minimum base dimension |
| Internal free-standing tower | ≤ **4 ×** minimum base dimension |
| Mobile tower | ≤ **4 ×** minimum base; outriggers if not met; casters locked; no persons/materials while moving |

Confirm against primary CSM / TG20 / manufacturer before Visible — ratios are common industry teaching.
